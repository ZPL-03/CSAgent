# CSDM_cph 项目状态

## 当前事实

- 项目目标为复合材料外压圆柱耐压壳智能设计。
- 主流程为耐压壳多智能体智能设计编排。
- LLM 配置读取项目根目录 `.env`，主模型使用 `LLM_PRIMARY_URL`、`LLM_PRIMARY_API_KEY`、`LLM_PRIMARY_MODEL_NAME`，回退模型使用 `URL`、`API_KEY`、`MODEL_NAME`。
- 工作站领域模型接口示例为 `LLM_PRIMARY_URL=https://csllm.ipen03.com/v1` 和 `LLM_PRIMARY_MODEL_NAME=csllm`。
- GUI 主流程只使用自然语言设计需求，需求中必须明确包含候选池总数和初筛保留数。
- LLM、案例迁移和 DOE 的初始来源配额按 `2:1:1` 计算，实际来源统计以规则检查后的有效候选为准。
- 任务记录包含 `user_input_facts`，该字段只保存用户自然语言明确给出的事实；普通几何数值写入 `geometry_reference`，只作为设计中心和几何包络依据；明确固定的几何数值写入 `fixed_geometry`。候选生成 LLM 读取该字段、外部知识库/知识图谱片段、LLM 候选数量、输出字段要求和系统候选字段约束。字段约束只限定材料库、参数范围和单位格式，不写成用户事实。
- LLM 候选由自然语言表格解析得到，候选编号不参与材料解析；`geometry_reference` 不覆盖模型候选参数，`fixed_geometry` 覆盖对应候选参数；模型候选行和回答原文保存在候选追踪字段中。
- LLM、案例迁移和 DOE 三路候选按材料、几何变量和铺层表达式去重；结构等价的重复方案不进入候选池，候选池缺口由 DOE 补足。
- 会话候选使用 `candidate_id=display_name=TMP_N`；进入有限元后正式输入使用 `candidate_id=display_name=C<N>`，并以 `session_candidate_id` 回溯会话候选。正式有限元结果文件和案例记录中的 `abaqus_results` 保留该回溯字段，便于离线重生成报告。
- LLM 候选缺少材料、长度、半径、厚度、alpha、beta 或缺陷比时不进入候选池；案例迁移来源必须提供完整候选几何；DOE 使用参数域生成完整候选并闭合候选池数量。
- 外部知识库读取本项目 `knowledge/external/rag/rag_chunks.jsonl`，当前文本块 51788 条。
- 外部知识图谱读取本项目 `knowledge/external/kg`，当前实体 2214 个、关系 480899 条。
- 外部知识库审计资料读取 `knowledge/external/provenance`，与 `CSDM_panel` 当前知识资产结构一致。
- 材料库、参数范围和代理公式已写入 `config/`。

## LLM 调用边界

- `TaskParser` 不调用 LLM，候选池数量、初筛保留数、载荷、几何参考值、固定几何约束和目标压力由规则解析得到。
- `CandidateGenAgent` 调用领域主模型生成 LLM 来源候选；输入为系统整理后的工程任务书，包含用户已给事实、外部知识库/知识图谱片段、LLM 候选数量、输出字段要求和系统候选字段约束，不把默认压力、默认材料或默认几何范围写成用户事实。
- `ReportGenAgent` 的任务事实、候选编号、压力数值、排序和有限元结论由结构化数据确定性生成；工程解释与制造建议可调用 LLM 做定性解释，输出出现结构化输入之外的新数值、阈值、材料牌号时先做约束清理，清理后仍不合规或调用失败时使用确定性解释。报告模板会清理 LLM 自带的重复章节标题，最终只保留一组“工程解释与制造建议”章节。
- `ScreenerAgent`、`FEMAgent`、`KnowledgeAgent`、`ConversationFlowController` 不调用 LLM。
