# CSDM_cph 接口约定

## 任务

自然语言入口必须明确给出候选池总数和初筛保留数。普通几何数值作为参考尺度，不强制所有候选固定；只有明确出现“固定”“限定”“必须等于”“保持不变”等表达时，才写入 `fixed_geometry`。字段级表达如“长度固定 500 mm”“半径必须等于 100 mm”“厚度限定 10 mm”属于固定几何约束。

示例任务：

```json
{
  "application": "复合材料外压圆柱耐压壳",
  "load_conditions": {
    "type": "external_pressure",
    "label": "外部静水压力",
    "external_pressure_MPa": 30.0
  },
  "boundary_conditions": {
    "type": "END_CLAMPED",
    "label": "两端固支"
  },
  "geometry_envelope": {
    "length_mm": [300.0, 800.0],
    "radius_mm": [80.0, 180.0],
    "thickness_mm": [5.0, 20.0],
    "alpha_deg": [10.0, 80.0],
    "beta_deg": [10.0, 80.0],
    "imperfection_ratio": [0.001, 0.01]
  },
  "candidate_generation_preferences": {
    "total_candidates": 12,
    "llm_candidates": null,
    "case_transfer_candidates": null,
    "doe_candidates": null,
    "source_allocation_mode": "ratio_2_1_1"
  },
  "screening_preferences": {
    "top_k_candidates": 5
  },
  "user_input_facts": {
    "candidate_generation": {
      "total_candidates": 12,
      "top_k_candidates": 5
    },
    "application": "复合材料外压圆柱耐压壳",
    "load_conditions": {
      "type": "external_pressure",
      "external_pressure_MPa": 30.0
    },
    "design_targets": {
      "ultimate_pressure_min_MPa": 35.0
    }
  },
  "hull_type": "CYLINDRICAL",
  "design_targets": {
    "ultimate_pressure_min_MPa": 35.0,
    "primary_objective": "最小壳体质量"
  }
}
```

`candidate_generation_preferences` 和 `screening_preferences` 是主流程必需控制参数。`total_candidates` 和 `top_k_candidates` 由自然语言任务明确给出。`llm_candidates`、`case_transfer_candidates`、`doe_candidates` 在自然语言入口保持 `null`，候选生成阶段按 `source_allocation_mode=ratio_2_1_1` 和 `config/app_config.yaml` 计算初始来源配额。

`user_input_facts` 只保存用户自然语言明确给出的事实。系统内部工程域参数用于 DOE、规则检查、候选变量完整性和有限元接口；候选生成 LLM 不把这些工程域参数读取为用户事实。LLM 输入包含 `user_input_facts`、外部知识库/知识图谱片段、当前 LLM 候选数量、输出字段要求和系统候选字段约束。

## 外部知识库/知识图谱

运行时入口为 `core.domain_knowledge.DomainKnowledgeBase`。配置项读取 `config/app_config.yaml` 的 `external_knowledge`：

- `rag_chunks_path`: `knowledge/external/rag/rag_chunks.jsonl`
- `kg_dir`: `knowledge/external/kg`
- `manifest_path`: `knowledge/external/manifest.json`
- `provenance_dir`: `knowledge/external/provenance`

当前外部知识资产与 `CSDM_panel` 使用同一版目录结构。RAG 文本块为 51788 条；知识图谱实体为 2214 个、关系为 480899 条；源登记、源元数据和结构化文档各 1931 条；结构化文本块为 400762 条；表格、图片和公式记录分别为 22800、44135 和 108500 条；Markdown 全文为 1931 份。

`format_snippets(task, top_k)` 返回候选生成 LLM 使用的文本片段列表。返回内容包含 RAG 片段、知识图谱关系和来源清单；RAG 片段按同一篇文献或同一来源保留最高分命中，图谱证据通过 `S1`、`S2` 这类标签合并引用。`provenance/` 只用于人工核查命中片段的源登记、结构化块、表格、图片、公式和 Markdown 全文上下文，不直接整体注入 LLM Prompt。

`retrieve(task, top_k, kg_top_k)` 返回结构化任务对应的 RAG 文本块和知识图谱关系，供候选生成和 GUI 证据预览使用。`retrieve_by_query(query, top_k, kg_top_k)` 返回人工工程检索词对应的证据，供 GUI “知识库”页人工核查使用。两类返回值均不直接作为候选结构化参数或工程数值事实源。

## 候选

```json
{
  "candidate_id": "TMP_1",
  "display_name": "TMP_1",
  "source": "DOE",
  "hull_type": "CYLINDRICAL",
  "geometry": {
    "length_mm": 500.0,
    "radius_mm": 100.0,
    "thickness_mm": 10.0,
    "alpha_deg": 40.0,
    "beta_deg": 70.0,
    "imperfection_ratio": 0.005
  },
  "layup": {
    "skin_layup": "[90_4/(±40/±70)_8/90_4]",
    "ply_count": 40
  },
  "material_system": {
    "name": "T700/Epoxy"
  },
  "origin_summary": "| S01 | T700/Epoxy | 500 | 100 | 10 | 40 | 70 | 0.005 | [90_4/(±40/±70)_8/90_4] | 结构稳定性和制造可行性均衡 |",
  "llm_output_excerpt": null
}
```

候选阶段 `candidate_id` 与 `display_name` 均使用 `TMP_N`。`persistent_candidate_id` 不是候选主身份字段；该字段可选，但出现时必须为非空字符串，正常候选生成不写入该字段。

LLM 来源候选经自然语言表格解析后进入结构化校验。`geometry_reference` 不覆盖 LLM 候选参数；`fixed_geometry` 覆盖对应候选参数。材料、长度、半径、厚度、alpha、beta 或缺陷比缺失时，LLM 候选不进入候选池。案例迁移来源必须来自具备完整设计字段的正式案例。LLM、案例迁移和 DOE 三路候选按材料、几何变量和铺层表达式形成结构等价签名；重复候选不进入候选池，缺口由 DOE 继续补足，最终会话候选重新编号为连续的 `TMP_<n>`。

## 初筛结果

- `surrogate_ultimate_pressure_MPa`：PBIPF 公式预测的极限压力
- `asme_linear_buckling_pressure_MPa`：ASME RD-1172 公式计算的线性屈曲压力，单位 MPa，在 PBIPF 公式中作为 `Q` 输入
- `surrogate_PBIPF_MPa`：PBIPF 公式压力代理值
- `surrogate_uncertainty_MPa`：PBIPF 公式 RMSE 给出的极限压力预测不确定度
- `surrogate_weight`：壳体面密度
- `rank_score`：排序分数

## 有限元结果

进入有限元前，正式输入沿用候选契约并改为 `candidate_id=C<N>`、`display_name=C<N>`，用 `session_candidate_id=TMP_<N>` 回溯会话候选；正式输入和案例设计不保留重复的 `persistent_candidate_id`。

```json
{
  "candidate_id": "C1",
  "display_name": "C1",
  "session_candidate_id": "TMP_1",
  "status": "success",
  "retry_count": 0,
  "ultimate_pressure_MPa": 32.5,
  "failure_pressure_MPa": 32.5,
  "linear_buckling_pressure_MPa": 35.1,
  "first_mode_eigenvalue": 35.1,
  "postbuckling_reference_pressure_MPa": 30.0,
  "riks_lpf_max": 1.0833,
  "imperfection_amplitude_mm": 0.525,
  "ultimate_pressure_basis": "一阶屈曲模态缺陷 Static Riks 最大 LPF × 基准外压",
  "failure_mode": "非线性后屈曲极限点",
  "weight_kg_per_m2": 15.5,
  "visualization_json": "data/abaqus_runs/C1/C1_mode1.json",

  "postbuckling_odb": "data/abaqus_runs/C1/C1_post.odb",

```

报告导出以当前已有有限元结果为范围。部分候选已经完成校核时，可以导出阶段报告；未校核候选不进入报告的有限元结果章节、结论统计和工程解释输入。

## 知识回流结果

状态图节点 `persist_knowledge` 接收 `task`、`fem_designs` 和 `results`，输出 `knowledge_updates`。`fem_designs` 保存已经晋级为正式编号的有限元输入，`results` 保存对应有限元结果。知识回流不调用 LLM，不修改有限元结果。

```json
{
  "status": "stored",
  "case_id": "CASE_1",
  "candidate_id": "C1",
  "session_candidate_id": "TMP_1",
  "retrained": false,
  "surrogate_summary": null
}
```

单个案例回流失败时，`status` 写为 `failed` 或 `missing_result`，并包含 `error` 字段；该失败进入工作流事件审计和 GUI 诊断，不改变 `results` 中的 Abaqus 数值。

## 运行审计报告

GUI “智能体流程”页的“导出运行审计”按钮调用 `workflow/run_audit.py`，读取当前 `run_id` 对应的工作流快照、事件审计和有限元作业队列，生成 Markdown 文件：

```text
data/results/run_audit_<RUN_ID>.md
```

运行审计报告包含以下内容：

- 运行摘要：阶段、人工确认点、任务、载荷、边界、候选数量、初筛数量、有限元结果数量、知识回流数量和报告路径。
- 智能体职责契约：状态图节点、运行时智能体、工具、LLM 边界和失败策略。
- 候选-结果-案例追踪：TMP 会话候选、正式 C 编号、代理预测、FEM 极限压力、代理误差、CASE 编号和回流状态。
- 有限元队列：作业编号、TMP 编号、C 编号、状态、结果摘要和错误摘要。
- LLM 调用轨迹：用途、选用后端、选用模型、是否回退和每次尝试状态。
- 诊断与事件审计：节点失败、工具失败、有限元失败、快照错误和完整事件列表。

运行审计报告只读取已经落盘的运行事实，不重新触发 LLM、代理模型、有限元或知识回流，不参与候选排序、案例编号或报告正文生成。

## 案例记录

案例记录保存在 `data/cases`，通过样本同步进入 `knowledge/case_library` 和案例记忆索引。`task_id` 是会话追溯字段，不是案例主身份字段；有真实任务来源时写入，没有真实任务来源时不写入。
