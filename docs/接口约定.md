`candidate_generation_preferences` 和 `screening_preferences` 是主流程必需控制参数。`total_candidates` 和 `top_k_candidates` 由自然语言任务明确给出。`llm_candidates`、`case_transfer_candidates`、`doe_candidates` 在自然语言入口中保持 `null`，候选生成阶段按 `source_allocation_mode=ratio_2_1_1` 和 `config/app_config.yaml` 计算初始来源配额。`top_k_candidates` 为正整数，且不大于候选池实际数量。

`user_input_facts` 只保存用户自然语言明确给出的事实。系统内部工程域参数可存在于任务契约字段中，用于 DOE、规则检查、候选变量完整性和有限元接口；候选生成 LLM 不读取这些工程域参数作为用户事实。LLM 输入包含 `user_input_facts`、外部知识库/知识图谱片段、当前 LLM 候选数量、输出字段要求和系统候选字段约束。字段约束只限定项目材料库、参数范围、单位和铺层格式，不叙述为用户输入。

LLM 来源候选经过自然语言表格解析后进入结构化校验。用户已给几何事实优先绑定到 LLM 候选；模型输出的候选行保存到 `origin_summary`，回答片段保存到 `llm_output_excerpt`。材料、长度、半径、厚度、alpha、beta 或缺陷比缺失时，LLM 候选不进入候选池。案例迁移来源必须来自具备完整设计字段的正式案例，缺失必要几何字段时直接跳过。

## 初筛结果

- `surrogate_ultimate_pressure_MPa`: PBIPF 公式预测的极限压力
- `asme_linear_buckling_pressure_MPa`: ASME RD-1172 公式计算的线性屈曲特征值 Q，单位 MPa，当前用于 PBIPF 输入
- `surrogate_PBIPF_MPa`: PBIPF 公式压力代理值
- `surrogate_uncertainty_MPa`: PBIPF 公式 RMSE 给出的极限压力预测不确定度
- `surrogate_weight`: 壳体面密度
- `rank_score`: 排序分数

## 有限元结果

进入有限元前，正式输入沿用候选契约并改为 `candidate_id=C<N>`、`display_name=C<N>`，用 `session_candidate_id=TMP_<N>` 回溯会话候选；正式输入和案例设计不保留重复的 `persistent_candidate_id`。
