# 工程设计报告

## 目的与结构

总体报告回答三个问题：哪些设计满足当前计算判据、为什么选择其中一个、哪些未验证事项会影响选型或工程放行。

- 设计需求与校核依据：载荷、边界、材料、固定尺寸、设计目标和计算范围。
- 全部候选方案与生成依据：候选参数、物理层序、来源和提案理由。生成理由是待验证的设计假设，不是承载结论。
- 预筛与送检依据：保留实际预筛记录，区分代理估计、人工选择和直接 FEM。未送检候选没有 FEM 判定。
- 有限元校核结果：原始结果、成功或失败状态、判定与候选编号的关联。
- 最终推荐设计方案：符合条件的方案比较表、推荐判断、方案取舍、决策边界与验证。

推荐仅针对本任务完成完整校核的候选，不表示全参数域最优。单个可比较结果只能支持该方案的条件性选用，不能证明其比未求解方案更优。

## 职责与证据

程序负责单位、数值、余量、优化目标排序、通过状态和编号关联。比较使用 `solved_design` 中的实际求解设计，材料、层序、几何、工况和边界通过修订指纹绑定结果。

LLM 负责解释：目标指标与承载余量之间的取舍、已观察到的方案差异、证据不足对设计决策的影响及相应验证动作。段落不是固定建议库的拼接。模型不能变更程序选出的推荐对象。

工程评议响应包含 `recommendation_candidate_id`、`assessment`、`tradeoffs`、`verification`。每段引用事实标记 `{{候选编号.指标}}`、`{{TASK.指标}}` 或检索证据标记 `{{E编号}}`，例如 `{{C1.ultimate_pressure_MPa}}`。数值、尺寸、层数和材料牌号通过事实标记写入，渲染读取对应值与单位；完整原值保存在事实 JSON。未确认指标列为证据缺失，不渲染成已知数值。正文不显示内部事实编号，审计 JSON 保存输入、原始响应、段落引用和接受状态。

报告解释阶段按当前任务检索内置 RAG/KG，依据来源身份、内容质量、适用范围、表格结构和上下文预算过滤证据。每个进入模型的证据单元保留原文、来源、适用条件和已绑定关系；预算不足时排除完整单元，不截断原文。`llm_explanation_audit.knowledge_retrieval` 保存检索数量、纳入与排除明细、知识包生成时间和源包哈希。检索不到可引用证据时，解释不能把未确认的背景内容写成当前设计事实。

契约校验检查结构、编号、引用、数值绑定和决策依据覆盖。有引用但格式不完整时，允许按具体错误修复一次。独立提示复核候选身份、指标含义、比较对象与因果边界；复核输入只包含事实、任务、引用证据和正式编号与会话编号的映射，不含提案理由或响应范例。拒绝意见必须包含正文原句及对应事实，出现实质错误时允许定向修订并复核一次。失败响应与原因留存，不能靠反复重试或固定建议文本取得通过。模型复核不证明解释绝对正确，最终报告仍需工程师审阅。

多变量同时变化的方案比较不能证明某一个变量造成性能差异；较小的计算余量不等于更高的缺陷敏感性。制造放行、试验认证及实际连接行为需有独立证据。

## 耐压壳判据

- 推荐依据：工作压力检查通过、全部铺层应力与损伤输出完整、Riks 极限点已确认，且极限压力不低于工作压力。
- 目标比较：按任务指定的质量、面密度、厚度或容量排序。容量余量 = 确认容量 / 工作压力 - 1。
- 分析范围：圆柱壳子模型；封头、法兰、层间分层和整机行为不在该模型的验证范围内。线性屈曲压力和首层失效指标不作为极限承载。

耐压壳质量按面密度乘壳中面面积计算，内、外半径输入按实际厚度换算为中面半径。容量余量表示当前计算容量与工作压力的差异，不等于规范安全系数或制造允许偏差。

## 失败与导出

显式关闭 LLM 时，报告保留确定性结果、比较和分析范围，不把模板文字称为模型解释。启用 LLM 时，API 失败或所有可用后端的评议均不合格会中止导出。耐压壳依照后端配置顺序调用；内容被拒绝的后端不重复调用，使用下一后端时记录拒绝原因和实际采用后端。

Markdown、PDF、事实 JSON 成组生成；生成失败不以旧 PDF 配对新正文。最终检查核对原始 FEM、排序、显示值、自然语言解释与逐页排版。报告重放复用真实求解工件，明确记录 `solver_executed=false`，不视作再次执行有限元。
