# 压力预筛模型

预筛使用线性压力估计和面密度排列候选。系数拟合采用有限元线性屈曲压力 Q，平台预测采用 ASME RD-1172 估算的 Q。设计是否满足工作压力，以对应有限元计算结果为依据。

## 线性公式

```text
D1 = log10(Q) * t / R
D2 = Q * D22 / (D33 - D12)
D3 = Q * Ir_permille * L / A22
P  = d1*D1 + d2*D2 + d3*D3 + d0

d1 = 185.77317089347608
d2 = 0.004656012009242315
d3 = -29.312096583264037
d0 = -0.04158270972383349
```

压力单位为 MPa，长度单位为 mm，R 为内半径。A22 的单位为 N/mm，D12、D22 和 D33 的单位为 N·mm。`imperfection_ratio` 以比例保存，描述符计算将其乘以 1000 转为千分比。项目候选采用 `0.008`，对应 `Ir_permille=8`。

拟合对三个描述符作标准化，并把拟合结果转换为工程单位系数。若标准化系数为 b、特征均值为 μ、标准差为 σ，则 `d=b/σ`，`d0=b0-Σ(d*μ)`。运行时直接使用工程描述符，不再次标准化。

## 拟合数据

`data/surrogate/regression_dataset.csv` 包含 4,269 条记录，目标列为 `maxP`，输入为 D1、D2 和 D3。Q 列保存有限元特征根压力。加载器依据 Q、几何、缺陷幅值和刚度复算描述符，检查存储精度范围内的一致性。`regression_metadata.json` 保存文件指纹、Q 定义、半径基准及单位。

拟合采用 `train_test_split(test_size=0.25, random_state=15)`，3,201 条记录用于最小二乘拟合，1,068 条记录用于测试。划分按记录随机进行，不代表按结构设计分组的独立泛化测试。

## 平台预测

平台根据候选材料、逐层角度和厚度计算 ABD 刚度，通过 ASME RD-1172 估算 Q，再代入同一线性公式。ASME 计算采用外半径；描述符 D1 采用内半径，两者均由候选的 `radius_reference` 换算。

`data/surrogate/design_dataset.csv` 包含 5,857 条完整记录，用于复算刚度并评估 ASME 代入预测。材料覆盖 T700/Epoxy、T800G/5228、M40J/TDE-85 和 IM7-8552。数据中的各缺陷工况保持其实际数值。`dataset_metadata.json` 保存单位、字段映射和文件指纹。

表内 A、B、D 的 16 个独立分量按材料和逐层角度复算，允许一位小数的舍入误差。`source_flag` 对应源表 SDV 列，现有字段说明未定义其物理含义，不用于拟合选样或判定设计是否通过。

## 误差与边界

| 评估 | Q 来源 | 样本数 | RMSE / MPa | 非正预测数 |
| --- | --- | ---: | ---: | ---: |
| 线性拟合训练集 | 有限元 | 3201 | 5.133 | 21 |
| 线性拟合测试集 | 有限元 | 1068 | 5.042 | 11 |
| 平台代入评估 | ASME RD-1172 | 5857 | 7.883 | 83 |

ASME 代入评估包含拟合数据对应的记录，不是独立留出测试。两类评估使用不同 Q，分别描述回归误差和平台应用误差，不能混用。

线性公式不保证预测为正。非正估计保留原值，在候选池标记为“预筛非正”，不计算排名、不自动入选 Top-K；人工仍可选择有限元校核。有效预测不足 K 个时，返回实际有效数量。正值估计不等于设计通过。超出训练描述符范围时，筛选说明标记外推状态。

## 复现与一致性

```powershell
conda activate AGENT
python -B scripts/fit_pressure_surrogate.py --output <项目外评估目录>
```

输出目录必须不存在。`regression_predictions.csv` 保存拟合表行号、训练或测试归属、有限元 Q、目标和预测；`deployment_predictions.csv` 保存平台评估样本编号、目标、预测及非正标记。`report.json` 保存系数、划分参数、两类误差、输入范围以及代码和数据指纹。

`config/param_ranges.yaml` 保存运行系数、拟合 Q 定义、预测 Q 方法和半径基准。模型加载时核对这些字段及计算代码、拟合数据和应用评估数据的指纹，不一致时报错。文本指纹采用 UTF-8、LF 换行且无 BOM 的内容，Windows 与 Linux 换行差异不改变指纹。案例比例校准独立于公式拟合，只有通过留一验证的正比例系数可以应用；非正公式估计不能用于比例校准。
