# 压力预筛模型

预筛模型按估计承载压力和面密度排列候选。有限元计算使用候选的几何、材料、逐层铺层、缺陷幅值、载荷及边界条件，设计结论以对应计算结果为依据。

## 数据

`data/surrogate/design_dataset.csv` 包含完整源表的 5,857 条记录，使用 mm、MPa 和千分比缺陷幅值。`inner_radius_mm` 表示内半径；`layup` 按从内表面到外表面的顺序记录铺层。`A`、`B`、`D` 分量分别采用 N/mm、N、N·mm。材料覆盖 T700/Epoxy、T800G/5228、M40J/TDE-85 和 IM7-8552。

`sample_id` 标识记录，`source_id` 和 `source_row` 定位来源。`dataset_metadata.json` 保存文件指纹、单位和字段映射。`source_flag` 对应源表的 `SDV` 字段，含 5,577 个值 1 和 280 个值 0；现有字段说明未定义其物理含义。

表中记录 A11、A12、A22、A33，以及 B、D 矩阵各 6 个独立分量。校验程序按逐层角度、总厚度和材料常数复算这 16 个分量，允许一位小数的舍入误差，缺列或超出容差时报错。源记录保留各工况的缺陷幅值；项目候选计算采用 `config/param_ranges.yaml` 中的 `analysis_assumptions.imperfection_ratio`。

## 描述符

```text
D1 = log10(Q) * t / R
D2 = Q * D22 / (D33 - D12)
D3 = Q * Ir_permille * L / A22
```

`Q` 是 ASME RD-1172 计算压力，采用外半径；上述 `R` 为中面半径。`Q` 的数值单位为 MPa，长度单位为 mm，系数按这一单位组合拟合。描述符结构见项目内资料 `data/surrogate/references/symbolic_regression_pressure_hulls.pdf`，DOI：`10.1016/j.compositesa.2026.109863`。论文的回归输入为有限元特征根，不能直接视为 ASME-Q 拟合。

回归表达式和系数位于 `config/param_ranges.yaml`：

```text
eta = d0 + d1*D1 + d2*D2 + d3*D3
P = s * log(1 + exp(eta / s))
```

`s` 与四个回归系数由建模集共同拟合。计算采用数值稳定的 `logaddexp`。

## 验证

设计组由材料弹性常数、实际层序、长度、内半径和总厚度确定，同一设计的不同缺陷工况进入同一组。`GroupShuffleSplit` 使用随机种子 42，将 20% 的设计组分配为测试集，得到 4,685 条建模记录和 1,172 条测试记录。

建模集采用五折分组交叉验证，随机种子为 42。每折的标准化参数和回归系数由该折训练数据计算。

选型在五折验证中比较直接线性回归和正值回归。符合正值要求的模型按 RMSE 选择，再用整个建模集拟合；测试集不参与选型和系数调整。

| 评估 | 样本数 | RMSE / MPa | MAE / MPa | 非正预测数 |
| --- | ---: | ---: | ---: | ---: |
| 线性回归五折验证 | 4685 | 6.583 | 3.791 | 65 |
| 正值回归五折验证 | 4685 | 6.555 | 3.696 | 0 |
| 正值回归测试集 | 1172 | 6.288 | 3.808 | 0 |

正值回归测试集的最大高估为 38.286 MPa，Spearman 排序相关系数为 0.9853。预筛按估计值排序，承载判定使用后续有限元结果。

`data/surrogate/validation/cross_validation.csv` 和 `testing.csv` 分别保存建模集与测试集的样本编号、设计组和预测值；建模集另记录交叉验证折号。`report.json` 保存划分参数、材料分组误差、输入范围和代码指纹。每条记录通过 `sample_id` 对应正式数据表。

拟合命令的输出目录必须不存在：

```powershell
python scripts/fit_pressure_surrogate.py --output <评估目录>
```

`core/pressure_regression.py` 定义回归形式，`core/surrogate_dataset.py` 校验数据并调用运行时刚度和描述符计算。候选排序读取 `config/param_ranges.yaml` 中的正值回归参数。参数、计算代码或数据与验证报告不一致时，模型加载失败；描述符超过建模集范围时，筛选说明记录外推状态。
