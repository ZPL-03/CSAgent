# 耐压壳案例迁移机制

## 检索对象

案例迁移只读取结构化历史案例，不把历史案例原文注入 LLM。候选生成阶段同时包含三条来源：

- `LLM`: 基于用户已给事实的领域主模型自然语言候选提案
- `CASE_TRANSFER`: 通过案例迁移
- `DOE`: 参数域采样

三路初始目标配额按 `LLM:CASE_TRANSFER:DOE = 2:1:1` 计算。案例迁移只消费正式案例库中真实存在且满足可迁移条件的案例；可迁移案例数量少于初始配额时，实际案例迁移数量减少，不把同一案例复制成多个迁移候选，也不把其他来源伪装成案例迁移结果。候选池总数由 DOE 参数采样完成数量闭合。

## 可迁移条件

正式迁移案例必须满足：

- `status == "success"`
- `verdict == "通过"`
- `hull_type == "CYLINDRICAL"`
- 工况类型为 `external_pressure`
- 边界类型一致
- 材料相同或未显式约束材料

## 排序指标

结构化排序使用以下差异：

- 外压目标差异
- 壳长 `length_mm` 差异
- 半径 `radius_mm` 差异
- 厚度 `thickness_mm` 差异
- 初始缺陷比 `imperfection_ratio` 差异
- 历史极限压力与当前目标极限压力差异

案例记忆向量索引用于辅助排序，不替代结构化硬过滤。

## 迁移结果

迁移候选会重新绑定当前任务的工况、边界、材料和目标，再执行规则检查。每条历史案例最多形成一条迁移候选；历史设计缺少长度、半径、厚度、铺层角或缺陷比等必要几何字段时直接跳过。通过规则检查后才进入统一候选池。
