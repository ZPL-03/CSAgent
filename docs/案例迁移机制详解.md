# 耐压壳案例迁移机制

## 检索对象

案例迁移只读取结构化正式案例，不把历史案例原文注入 LLM。候选生成阶段同时包含三条来源：

- `LLM`：基于用户已给事实、项目知识库/知识图谱片段和候选字段约束生成自然语言候选提案
- `CASE_TRANSFER`：从正式案例库中检索可迁移案例
- `DOE`：在参数域内进行确定性采样

三路初始目标配额按 `LLM:CASE_TRANSFER:DOE = 2:1:1` 计算。每条满足迁移条件的案例最多生成一条候选，来源记录为 `CASE_TRANSFER`。数量不足时由 DOE 补齐，补齐候选的来源记录为 `DOE`。

## 可迁移条件

正式迁移案例必须满足：

- `status == "success"`
- `verdict == "通过"`
- `hull_type == "CYLINDRICAL"`
- 工况类型为 `external_pressure`
- 边界类型一致
- 材料相同，或当前任务未显式约束材料
- 历史设计包含长度、半径、厚度、alpha、beta 和缺陷比等必要几何字段

## 排序指标

结构化排序使用以下差异：

- 外压目标差异
- 壳长 `length_mm` 差异
- 换算到当前任务基准的半径差异
- 厚度 `thickness_mm` 差异
- 初始缺陷比 `imperfection_ratio` 差异
- 历史极限压力与当前目标极限压力差异

同一工况匹配等级内，具有有效容量证据的案例优先参与压力距离比较；容量未知的案例按其余输入相似度排列。线性屈曲压力和任务目标值不替代容量压力。任务未给出的几何尺寸和目标压力不参与距离计算；案例缺少比较所需的几何字段时排在完整记录之后。缺陷距离以项目配置值 0.008 为目标。案例记忆向量索引用于辅助排序，不替代结构化硬过滤。

## 迁移结果

迁移候选绑定当前任务的工况、边界、材料、目标及项目配置的初始几何缺陷比，再执行规则检查。缺陷比采用 0.008，历史值保存在来源审计中；历史案例及其求解结果不改写。每条历史案例最多形成一条迁移候选；历史设计缺少必要几何字段时直接跳过。通过规则检查后，迁移候选进入统一候选池，并与 LLM、DOE 候选按结构等价签名去重。
