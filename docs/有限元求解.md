# 圆柱耐压壳有限元求解

## 输入与模型范围

`FEMAgent` 接收完整候选 JSON，包括材料弹性与强度、圆柱壳几何、逐层角度、外部压力、边界和设计目标。`abaqus/wangge.py` 为求解入口，`runtime_build_pressure_hull.py` 建立复合材料圆柱壳模型。金属封头、法兰和连接未显式建模，端部约束按候选边界设置实现。因此结论属于圆柱壳子模型，不是整机安全认证。

每层使用三个厚度积分点。服务压力、目标压力和损伤分析输出全部铺层积分点；逐单元、逐面内积分位置检查覆盖率，不能只检查全模型积分点号的并集。缺失任意铺层应力时，不给出完整设计校核通过结论。

## 求解阶段

1. 单位外压线性屈曲：提取第一正特征值及一阶模态。
2. 精确服务压力：在指定服务压力下检查屈曲裕度和二维 Hashin 起始失效；不通过时保留真实结果并停止后续容量计算。
3. 精确目标压力：独立加载至目标值，检查全部铺层应力；不通过时不继续容量计算。
4. Static Riks：引入一阶模态几何缺陷，运行几何非线性及启用的场变量损伤模型，记录 LPF 和状态变量。

求解成功与设计通过是不同状态。设计不通过是有效工程结果，不应被识别为软件故障或通过自动改尺寸掩盖。重试如改变几何或分析设置，必须生成新的设计修订号。

## 场变量损伤模型

`zhangusdfld.for` 使用材料局部应力，强度单位为 MPa。每个作业单独生成 `pressure_hull_strength.inc`，包含候选的 `Xt/Xc/Yt/Yc/S`。以下触发条件达到一时，状态变量不可逆地置为一：

| 状态变量 | 触发条件 | 刚度退化 |
| --- | --- | --- |
| SDV1：横向 | 横向拉伸或压缩应力比平方与面内剪切应力比平方之和 | E2 保留十分之一，泊松比置零，剪切刚度保持 |
| SDV2：压缩剪切 | 纤维压缩应力比平方与面内剪切应力比平方之和 | E2、剪切刚度保留十分之一，泊松比置零 |
| SDV3：纤维 | 纤维拉伸或压缩应力比平方 | E1 保留百分之十四，E2、剪切刚度保留十分之一，泊松比置零 |

多个标记同时激活时采用对应组合的退化表。USDFLD 使用增量起始状态更新场变量，损伤演化对网格、增量和退化参数敏感。该模型不含断裂能正则化、层间分层、连接损伤或试验标定，不能把数值求解可运行等同于材料模型已充分验证。服务/目标压力的二维 Hashin 1980 判据仅用于损伤起始校核，与上述场变量退化触发式并不相同。

## 容量证据

独立监测进程读取 `.sta` 中已收敛增量的 LPF；峰后至少三个收敛点且相对峰值下降达到百分之二十时，调用 Abaqus 终止命令并保存监测证据。监测不依赖 CAE 图形消息回调，也不依赖无界面同步提交期间的 Python 线程调度。

最终极限点必须由 ODB 载荷路径再次确认。正常完成作业或具有匹配后峰终止证据的作业才可形成容量结论；其他中止、增量上限或仅有观测最大 LPF 不构成极限压力。材料容量还要求损伤子程序确实执行、SDV1 至 SDV3 输出完整。若子程序已执行但没有损伤激活，结果只表示该路径中几何失稳先控制，不声称发生了材料损伤破坏。

## 运行与产物

项目使用 AGENT Python；Abaqus 自带 Python 执行建模与 ODB 读取。Windows 本地子程序编译需要兼容的 Intel Fortran Classic、MSVC 和 Abaqus。`ONEAPI_ROOT` 指向含 `setvars.bat` 的目录时，编译环境仅加载到求解子进程。

作业目录保留 `.inp`、`.odb`、`.sta`、`.msg`、`.dat`、`.log`、候选输入、子程序、强度 include 文件和后峰监测 JSON。结果保存源文件与强度文件哈希、应力覆盖、损伤状态、服务与目标压力结论、Riks 终止依据及容量证据。GUI 的 FEM 视图当前显示一阶线性屈曲模态，不是应力或损伤云图。
